# Arka plan müziği (masal videosu)

Masal videolarına sakin bir arka plan müziği (ninni) eklemek için bu klasöre
**`lullaby.mp3`** adında telifsiz bir ses dosyası koy.

- Dosya adı tam olarak `lullaby.mp3` olmalı.
- Telifsiz/royalty-free, sakin/enstrümantal bir ninni öner (örn. Pixabay Music,
  YouTube Audio Library "lullaby" / "ambient" kategorisi).
- Dosya yoksa video **müziksiz** (sadece seslendirme) oluşturulur — sorun olmaz.

Eklediğin müzik videoda otomatik olarak düşük seviyede (seslendirmenin altında)
mikslenir.
