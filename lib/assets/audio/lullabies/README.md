# Ninni parçaları

Bu klasöre telifsiz (royalty-free) ninni / sakin enstrümantal / doğa sesi
`.mp3` dosyalarını ekle. Uygulamadaki "Ninni & Meditasyon" ekranındaki katalogla
eşleşmesi için dosya adlarını AYNEN şöyle koy:

| Dosya adı | Ekranda görünen |
|---|---|
| `lullaby_1.mp3` | Yıldız Ninnisi |
| `lullaby_2.mp3` | Ay Işığı |
| `lullaby_3.mp3` | Bulut Yolculuğu |
| `lullaby_4.mp3` | Yumuşak Yağmur |
| `lullaby_5.mp3` | Okyanus Dalgaları |

İstediğin kadarını ekleyebilirsin; eklemediklerin ekranda gri "Yakında" olarak
görünür. Eklediklerin döngüde (sürekli) çalar ve uyku zamanlayıcısıyla otomatik
durdurulabilir.

**Kaynak önerisi (ticari kullanıma uygun, telifsiz):**
- Pixabay Music (pixabay.com/music) — "lullaby", "sleep", "rain", "ocean"
- YouTube Audio Library — "Ambient" / "Calm" kategorileri

**Meditasyonlar** dosya gerektirmez — ElevenLabs ile anlık seslendirilir.
