# Doğa sesleri

Bu klasöre telifsiz (royalty-free) doğa sesi `.mp3` dosyalarını ekle.
Ekrandaki katalogla eşleşmesi için dosya adlarını AYNEN şöyle koy:

| Dosya adı | Ekranda görünen |
|---|---|
| `nature_rain.mp3` | Yağmur |
| `nature_forest.mp3` | Orman |
| `nature_ocean.mp3` | Okyanus |
| `nature_fire.mp3` | Şömine |

Eklemediklerin "Yakında" görünür. Eklediklerin döngüde (sürekli) çalar,
**arka planda** (ekran kapalıyken) devam eder ve uyku zamanlayıcısıyla durur.

**Kaynak:** Pixabay Music / YouTube Audio Library — "rain", "forest", "ocean",
"fireplace" / "crackling fire".
