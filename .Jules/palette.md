## 2024-05-23 - Dynamic Tooltips for Toggle Buttons\n**Learning:** Toggle buttons (like Favorites) require dynamic tooltips that reflect the current state (e.g., "Add to Favorites" vs "Remove from Favorites") rather than a static label. This acts as the accessible name for screen readers.\n**Action:** Always check `isFavorite` (or similar state) to switch between localized strings for the tooltip.
